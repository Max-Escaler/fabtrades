# TCG Collection Tracking Apps — Competitive Landscape

**Research date:** 2026-08-04  
**Method:** Primary sources preferred (official websites, App Store / Google Play listings, official help/docs). Secondary sources used only where noted (e.g. founding history).  
**Scope:** Collection / portfolio / checklist / scan tools used by TCG collectors — not pure deckbuilders unless they also manage collections.

---

## Branding note (Collectr)

**Collectr is not a rebrand of TCGplayer Collection.** It is an independent portfolio app founded ~2021–2022 (Collectr Inc., Vaughan ON). TCGplayer maintains its own marketplace app with separate collection/list features. Collectr sources market data (including affiliate listings involving TCGplayer/eBay) but is not owned by TCGplayer.

Sources: [getcollectr.com](https://www.getcollectr.com/), [Play Store listing](https://play.google.com/store/apps/details?id=com.collectrinc.collectr), [BetaKit interview (founding story)](https://betakit.com/how-collectr-bootstrapped-a-trading-card-hobby-into-an-eight-figure-business/).

- Portfolios for raw, graded, and sealed products ([homepage](https://www.getcollectr.com/)).

- Unlimited portfolios on Free tier ([PRO page](https://getcollectr.com/pro)).
- Showcase profiles for displaying collections ([social page](https://getcollectr.com/social)).

### Portfolio / value
- Live market value charted over time (“like a stock portfolio”).
- Cost basis & gains/losses; multi-currency including crypto ([homepage](https://www.getcollectr.com/), [Play Store](https://play.google.com/store/apps/details?id=com.collectrinc.collectr)).
- Price guide for raw/graded with pop reports; PRO unlocks up to 5+ years of price history ([PRO](https://getcollectr.com/pro)).
- Biggest gains/losses / trending movers.

### Set completion / checklists
- Set deep links and set browsing referenced in product updates ([Play Store “What’s new”](https://play.google.com/store/apps/details?id=com.collectrinc.collectr)); primary positioning is portfolio value, not master-set checklists.

- Camera scan to identify set, number, variant and add to collection ([homepage](https://www.getcollectr.com/)).
- Unlimited scanning is a PRO feature ([PRO](https://getcollectr.com/pro)).

### Wishlist
- Not prominently documented on marketing pages as a first-class “wishlist” product; social/showcase and search are emphasized instead.

- Collection export is PRO (“Seamless Export”) ([PRO](https://getcollectr.com/pro)).

### Alerts / notifications
- Not heavily marketed on primary pages; partner perks / broadcast DMs listed as PRO/coming soon ([PRO](https://getcollectr.com/pro)).

- Trade Analyzer: two-sided deal with fairness meter, cash balance, condition/variant/grade, singles + sealed, USD/CAD ([trade](https://getcollectr.com/trade)).

- Free to start; Collectr PRO ≈ **$4.99/mo billed annually ($59.99/yr)** or **$7.99/mo** ([homepage](https://www.getcollectr.com/), [PRO](https://getcollectr.com/pro)).
- PRO: unlimited scanning, 5+ yr pricing, exclusive filters, export, search history, custom backgrounds, partner perks, PRO icon/badge.

### Standout unique features
- Multi-TCG **investment-style portfolio** (raw + graded + sealed) at large scale.
- Trade Analyzer with shareable Trade View.
- Creator/social layer for collectors.

## 2. ManaBox

| Field | Detail |
| --- | --- |
| **Official site / docs** | [manabox.app](https://manabox.app/), collection guides under `/guides/collection/` |
| **Games** | Magic: The Gathering only (unofficial companion) ([App Store](https://apps.apple.com/us/app/manabox-mtg/id1460407674)) |
| **Platforms** | iOS, Android; web features exist for shared deck links; desktop version mentioned as future ([subscriptions FAQ](https://www.manabox.app/guides/general/subscriptions/)) |

### Collection features
- **Binders** = owned cards (named after physical binders for location) ([getting started](https://manabox.app/guides/collection/getting-started/)).
- **Lists** = wishlists, buylists, tracking lists (not ownership).
- Quantity, foil, language, condition, misprint, altered, purchase price/currency ([import/export](https://www.manabox.app/guides/collection/import-export/)).
- Bulk edit; partial quantity moves; add complete sets ([FAQ](https://manabox.app/guides/collection/faq/)).
- Physical deck registration alongside binders.

### Portfolio / value
- Multi-marketplace prices: TCGplayer, Cardmarket, Card Kingdom, Star City Games, Cardhoarder, Mana Pool ([App Store](https://apps.apple.com/us/app/manabox-mtg/id1460407674)).
- Purchase-price-based gain/loss %; default cost = price on day added ([FAQ](https://manabox.app/guides/collection/faq/)).
- **Limitation:** providers supply global values — app does **not** price by condition/language/location ([prices guide](https://www.manabox.app/guides/general/prices-in-the-app/)).

### Set completion / checklists
- **Collector mode**: have/missing by set (and subsets), color, type, rarity; group printings; sort by completion % ([collector mode](https://manabox.app/guides/collection/collector-mode/)).

### Scan / OCR
- Built-in camera scanner ([App Store](https://apps.apple.com/us/app/manabox-mtg/id1460407674)).

### Wishlist
- Via Lists (wishlist / buylist) ([getting started](https://manabox.app/guides/collection/getting-started/)).

### Import / export
- CSV import/export with rich columns; text (MTGA-style) import; buy-list deep links to TCGplayer / Card Kingdom ([import/export](https://www.manabox.app/guides/collection/import-export/)).
- Documented TCGplayer app CSV column requirements for import.

### Alerts / notifications
- Not a primary marketed feature in collection docs.

### Social / trading / marketplace
- Trade tool for fairer/faster trades ([App Store](https://apps.apple.com/us/app/manabox-mtg/id1460407674)).
- Share decks via browser links; share cards with marketplace links.
- Not a full peer marketplace.

### Monetization
- Free core search/collection; **ManaBox PRO** ≈ **$2.49/mo** or **$22.99/yr**; one-time “Remove ads” ≈ $1.99 ([App Store](https://apps.apple.com/us/app/manabox-mtg/id1460407674)).
- PRO: cloud sync (up to 5 devices), ability to create new binders / Pro-only features; data retained if subscription lapses ([subscriptions](https://www.manabox.app/guides/general/subscriptions/), [cloud sync](https://www.manabox.app/guides/sync/cloud-sync/)).

### Standout unique features
- Deep **player/collector** MTG tooling (deck sim, offline search, binder location mirroring).
- Collector mode + multi-price-provider switch.
- Strong CSV interoperability with other MTG tools.

## 3. Delver Lens / Delver (Delver Lab)

| Field | Detail |
| --- | --- |
| **Official sites** | [delverlab.com](https://www.delverlab.com/), [delver.app](https://delver.app/) |
| **Games** | Magic: The Gathering (primary). Branding also references Poke Delver™ trademark on delver.app footer — treat Pokémon as emerging/branded, not fully documented on primary MTG pages. |
| **Platforms** | **Delver Lens**: Google Play (OG Android). **Delver / Delver X**: iOS App Store, web/PWA (Android/desktop browsers). Chrome extension historically listed. |

### Collection features
- Scan-to-inventory; lists & decks; search collection; language/condition/tags referenced in changelog on delverlab.com.
- Free: unlimited cards to add ([delver.app](https://delver.app/)); performance guidance suggests organizing into lists for large collections.

### Portfolio / value
- Prices from TCGplayer, Cardmarket (MKM), Card Kingdom, CardHoarder, MageMarket/Magus Market (Brazil) depending on client ([Play Store](https://play.google.com/store/apps/details?id=delverlab.delverlens), [iOS](https://apps.apple.com/us/app/mtg-delver-tcg-scanner/id6504142186), [delver.app](https://delver.app/)).
- Currency conversion; price history for collection/sets (changelog mentions ~2 years offline-downloadable history on delverlab.com).
- Buy/sell deep links (Card Kingdom, TCGplayer Direct CSV, Card Conduit, MTGStand, LigaMagic, etc.).

### Set completion / checklists
- Not the product’s primary pitch; scanning + export to collection managers is the focus.

### Scan / OCR
- Full-card camera recognition (Alpha → current); tokens/emblems ([Play Store](https://play.google.com/store/apps/details?id=delverlab.delverlens)).
- Delver X: multiple recognition models; advanced models on paid tier ([delver.app](https://delver.app/)).
- Delver Lens uses a free “lambda”-class model (paid on Delver X) ([delver.app](https://delver.app/)).

### Wishlist
- Lists can serve wishlist-like roles; not branded as strongly as Deckbox Wishlist.

### Import / export
- **Major differentiator:** export presets to Archidekt, CardSphere, Deckbox, DeckStats, EchoMTG, MTGGoldfish, MTGStand, MyCardInventory, PucaTrade, QuietSpeculation, TappedOut, Moxfield, CubeCobra, TopDecked, CSV/Excel, webhooks ([Play Store](https://play.google.com/store/apps/details?id=delverlab.delverlens), [delver.app](https://delver.app/)).
- Free export capped (~105 cards on Delver X); unlimited on paid ([delver.app](https://delver.app/)).

### Alerts / notifications
- Not a primary feature on marketing pages.

### Social / trading / marketplace
- Integration hub to marketplaces and trade sites rather than a social network.

### Monetization
- Free for most users; **$4/month** Pro: ad-free (already free claims ad-free on new site), sync, advanced recognition models, unlimited export, cloud image backup up to 10GB, webhooks ([delver.app](https://delver.app/)).
- Changelog notes prior subscription price increase $3→$4 (grandfathered) ([delverlab.com](https://www.delverlab.com/)).

### Standout unique features
- **Interoperability hub** — scan once, push everywhere.
- Long-running scanner reputation (since ~2016); privacy-focused messaging on delver.app.

## 4. Deckbox.org

| Field | Detail |
| --- | --- |
| **Official site** | [deckbox.org](https://deckbox.org/) |
| **Games** | Magic: The Gathering (primary). Help also lists World of Warcraft TCG and Warhammer: Invasion ([getting started](https://deckbox.org/help/start)). |
| **Platforms** | Web (desktop + [mobile web](https://deckbox.org/mobile)); native **iOS and Android apps** with scanner (confirmed in [privacy policy](https://deckbox.org/privacy) and [Premium](https://deckbox.org/premium)). |

### Collection features
- Auto-created **Inventory**, **Tradelist**, **Wishlist** per game ([getting started](https://deckbox.org/help/start)).
- Foil, condition (Mint → Damaged), language, signed, artist proof, misprint, promo, textless ([forum CSV headers discussion](https://deckbox.org/forum/topics/29071); import/export help).
- Premium: unlimited inventory **tags** (binders, boxes, sale lists, grading piles, loans), photos/scans, edition completion views ([premium](https://deckbox.org/premium)).

### Portfolio / value
- Automatic valuing in trade UI; historical pricing from TCGplayer discussed on site forums.
- Not positioned as a stock-style P&L portfolio (contrast Collectr/EchoMTG).

### Set completion / checklists
- Premium: “Check edition completion” / more cards per page when reviewing large sets ([premium](https://deckbox.org/premium)).
- Full editions database ([editions](https://deckbox.org/editions)).

### Scan / OCR
- Mobile app camera scanner; Premium unlocks **unlimited scanner additions** ([premium](https://deckbox.org/premium), [privacy](https://deckbox.org/privacy)).

### Wishlist
- First-class Wishlist + import ([getting started](https://deckbox.org/help/start)).

### Import / export
- CSV import/export for inventory, tradelist, wishlist ([exports and imports](https://deckbox.org/help/exports_and_imports)).
- Paste-import from other sites/spreadsheets.

### Alerts / notifications
- Community/event notifications; trade-related feedback system ([homepage](https://deckbox.org/)).

### Social / trading / marketplace
- **Core strength:** trade matching based on overlapping Inventory/Tradelist/Wishlist; built-in trade workflow, sent/received tracking, feedback/reputation ([homepage](https://deckbox.org/)).
- Deck sharing, comments, communities, event organizer.
- Not a payment marketplace (peer trading facilitation).

### Monetization
- Free unlimited cards/decks with ads.
- Premium ≈ **$3.99/mo annual ($47.88/yr)** or **$5.99/mo** (USD; EUR equivalents) ([premium](https://deckbox.org/premium)).
- Premium: no ads (web), tags, scanner limits, private inventories, deck-from-inventory tools, support/recovery.

### Standout unique features
- Since **2008** — deepest MTG **trade-matching** social collection site.
- Inventory ↔ Tradelist ↔ Wishlist model still the template many apps copy.

### Scan / OCR
- First-party scanner for every TCGplayer game; multi-card scanning supported in seller workflow guide ([scan guide](https://help.tcgplayer.com/hc/en-us/articles/23531246396183-How-to-Setup-and-Use-the-TCGplayer-App-for-Card-Scanning)).

- Marketplace/order notifications (platform-wide); not a dedicated collection price-alert product in FAQ.

### Social / trading / marketplace
- Full **buy marketplace**; seller inventory upload from app.
- Not peer-to-peer trade matching like Deckbox.

### Monetization
- App **100% free** including seller scan upload for Level 4 ([seller page](https://seller.tcgplayer.com/mobile-app)).
- Revenue via marketplace take rates / seller fees (platform business model).

### Standout unique features
- Broadest **first-party multi-game scanner** tied to the largest US TCG marketplace.
- Seller inventory pipeline from phone → Seller Portal.

## 6. Cardmarket (collection-adjacent features)

| Field | Detail |
| --- | --- |
| **Official** | [cardmarket.com](https://www.cardmarket.com/), [help.cardmarket.com](https://help.cardmarket.com/) |
| **Games** | Large EU-centric catalog: MTG, Pokémon, Yu-Gi-Oh!, and many others (ongoing additions; e.g. Riftbound announced 2025) ([Insight article](https://www.cardmarket.com/en/Insight/Articles/whats-new-on-cardmarket-8-2025)) |
| **Platforms** | Web-first marketplace. **No official Cardmarket collection-scanner app** identified in primary sources; third-party apps consume Cardmarket prices/API. |

### Collection features
- **Not a personal “owned collection” tracker.** Closest analogs:
  - **Wants lists** (buying intent): up to 100 lists/game, 150 entries/list; min condition, wish price, foil/altered/signed/first-ed flags, mail alert ([Wants help](https://help.cardmarket.com/en/wants-list), [API](https://api.cardmarket.com/ws/documentation/API_2.0:Wantslist_Item)).
  - **Seller Stock**: quantity, condition, language, price, comments for articles **listed for sale** ([Stock API](https://api.cardmarket.com/ws/documentation/API_2.0:Stock_Management)).

### Portfolio / value
- Price guides / catalog downloads for external tracking ([State of Cardmarket 2024](https://www.cardmarket.com/en/Insight/Articles/the-state-of-cardmarket-2024) — public price guide & product catalog announced).
- No built-in personal P&L portfolio product on Cardmarket itself.

### Set completion / checklists
- Catalog/expansions browsing; not a collector checklist product.

### Scan / OCR
- None official.

### Wishlist
- Wants lists + Shopping Wizard / “sellers with most cards” ([Shopping Wizard](https://help.cardmarket.com/en/ShoppingWizard)).

### Import / export
- Seller stock CSV/export via API and site tools ([Export Own Stock](https://api.cardmarket.com/ws/documentation/API_2.0:Export_Own_Stock)).
- Order/sales CSV exports for accounting.

### Alerts / notifications
- Wants `mailAlert` flag in API; marketplace order messaging; Trustee Service for tracked shipments ([Trustee](https://help.cardmarket.com/en/TrusteeService)).

### Social / trading / marketplace
- Dominant **European peer + professional marketplace** with reputation, shipping, trustee payments.

### Monetization
- Marketplace fees; seller plans/professional tools (not freemium collection SaaS).

### Standout unique features
- Shopping Wizard for multi-seller wants fulfillment.
- Public catalog/price datasets for third-party collection apps.

**Implication for Fabtrades:** treat Cardmarket as a **price + sell channel**, not a Collectr/ManaBox competitor for owned-collection UX.

## 7. Dragon Shield Scanner / Card Manager apps

Arcane Tinmen (Dragon Shield) ships **separate apps per TCG**, not one multi-game app.

| --- | --- |
| MTG Scanner - Dragon Shield | [App Store](https://apps.apple.com/us/app/mtg-scanner-dragon-shield/id1460657155), [Play](https://play.google.com/store/apps/details?id=pt.tscg.mtgmanager) |

| YGO Scanner - Dragon Shield | [Play](https://play.google.com/store/apps/details?id=pt.tscg.yugiohmanager) |

### Shared feature pattern (from store listings)
- **Scan** any language; **AR/real-time translation** of foreign cards (standout).
- Prices: TCGplayer + Cardmarket (MTG also lists Card Kingdom, MTGMintCard on iOS).
- 30-day price history charts.
- Collection folders with custom images; folder valuation / win-loss over time.
- Wishlists + tradelists; **trade comparison tool** (who’s ahead).
- Deck builder + sideboard; CSV/text export.
- Friends: view friends’ collections/decks/wish/trade lists.
- Weekly collection email summaries.
- Top winners/losers movers.
- FaB listing explicitly: “Manage your collection **for free**” + unlimited decks ([FaB Play](https://play.google.com/store/apps/details?id=com.dragonshield.fabmanager)).

### Monetization
- Free download with IAP subscriptions. MTG iOS lists tiers such as Premium Monthly ~$3.99, Premium Yearly ~$29.99–$39.99, plus Common/Uncommon/Rare SKUs ([MTG App Store](https://apps.apple.com/us/app/mtg-scanner-dragon-shield/id1460657155)).
- Historical interview content (secondary) described ads removal + historical price access as premium; store copy now emphasizes Pro Scanner accuracy. Treat exact free-card caps as **verify-in-app** (third-party reviews claim ~100-card free limits — not confirmed on Dragon Shield marketing pages fetched here).

### Standout unique features
- Brand trust of Dragon Shield; **AR card translation**.
- Per-game apps including a dedicated **FaB** scanner.
- Trade balancer + social friends lists.

## FAB Trades gap summary

FAB Trades is a **Flesh and Blood trade companion** (Binder = trade stock, not full owned inventory). Relative to the landscape above, the highest-impact missing collector features are:

| Priority | Gap | Pattern to copy |
| --- | --- | --- |
| High | Full owned **Inventory** layer (keep Binder as tradelist) | Deckbox Inventory → Tradelist → Wishlist |
| High | Set completion / missing checklist | ManaBox Collector mode, CollectFlesh, TCG Collector |
| High | CSV import/export | Nearly all serious tools; Collectr export = PRO |
| High | Price history charts + portfolio value over time | Collectr / EchoMTG; Dragon Shield 30-day charts |
| Medium | Multi-folder / location binders | ManaBox, Dragon Shield folders |
| Medium | Live CardMarket (toggle exists; ingest off) | Dragon Shield, ManaBox, Delver |
| Medium | Cost basis, movers, alerts/digests | Collectr, EchoMTG, Dragon Shield weekly emails |
| Low / intentional | Multi-TCG, sealed, graded slabs | Collectr-class; not required for trade wedge |

**Keep as differentiators:** mid-trade balancer, Confirm Trade → binder reconcile, Discord offer paste, Trade Filler, Lend tracker, Life Tracker.

## Research caveats

1. **Store listings vs in-app:** Free limits (scan caps, binder caps, card caps) change frequently; always re-verify in-app before product decisions.
2. **Cardmarket** should not be scored as a collection tracker competitor; score it as marketplace + wants + seller stock.
3. **Collectr ≠ TCGplayer Collection** — common community confusion; keep branding separate in docs/marketing.
4. **FaB-specific** mobile options exist but are fragmented; multi-game Collectr/TCGplayer may still dominate FaB collectors’ portfolios.
5. This document does not rank download counts beyond what store pages claim (e.g. Collectr Play “1M+” downloads / marketing “millions of users”); App Store ranking APIs were not queried.
